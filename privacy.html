Who we are

Health Coach Fitbit Bridge ("the app") is a personal, single-user tool built and operated by 费驰 (Adam Fei) for his own use. It is not a commercial service.

Google user data accessed

With the user's consent, the app uses read-only Google Health API scopes to access the user's own Fitbit data, including activity (steps, active zone minutes, exercise), sleep, heart rate (including resting heart rate and heart rate variability) and related health metrics.

How the data is used

The data is used only to produce daily personal health summaries for the owner. It is not used for advertising, profiling, credit or lending decisions, or any purpose unrelated to providing these summaries.

Storage

Data and OAuth tokens are stored locally on the owner's own computer. The app does not operate a server that collects user data.

Sharing

Google user data is not sold, shared with, or transferred to any third party, and is not used to serve ads. No humans other than the owner read the data.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

You can revoke the app's access at any time at myaccount.google.com/permissions. To request deletion of locally stored data, email the contact address below; the data will be deleted from the owner's computer.

数据和 OAuth 令牌仅保存在本人自己的电脑上。本应用不运营任何收集用户数据的服务器。

共享

Google 用户数据不会被出售、共享或转让给任何第三方，也不会用于投放广告。除本人外，没有任何人会读取这些数据。

本应用对从 Google API 获取信息的使用和转移遵守 Google API 服务用户数据政策，包括其中的"有限使用"（Limited Use）要求。
